# Android TV IPTV 首版设计

目标：Android 10 / API 29 及以上。APK 是交互参考，用户给出的五个 URL 是频道来源。实现原生 Kotlin / Android Views，Media3 1.11.1 播放器，播放线路共享 OkHttp 连接池。

## 交互

打开应用先读取频道缓存，自动播放指定默认频道；首次优先 CCTV1，没有则播放首个频道。默认频道丢失时播放回退频道并提示，保留原设置以便后续源恢复。

全屏方向键换台 / 换线路，确定键释放时打开选台抽屉，避免同次松键误选。抽屉为分类 / 频道两列，顶部搜索和菜单。按确定播放，长按确定 / 菜单操作当前焦点频道：设置默认、收藏、选线路。默认 `★`、收藏 `♥` 独立。全屏返回两次退出，抽屉返回一次关闭。

## 数据与恢复

- 五个源并行请求，各有 6 秒连接、8 秒读取超时；下载体最多 8 MiB，读取循环有 25 秒预算。
- AtomicFile 保存各源 UTF-8 原始列表。每次更新保留其他源数据；失败、空列表 / 公告列表不能覆盖已成功缓存。
- 解析器支持 UTF-8 BOM、M3U 引号属性 / EXTGRP / EXTVLCOPT、TXT 分类 / 多线路；仅接受有主机的 HTTP / HTTPS URL。
- 标准 CCTV 名称、常见画质括号规范化为稳定频道 key；其他名称只规范大小写 / 空白。不按条目序号或 URL 保存默认频道。
- 同 key 的 URL + headers 去重，保留不同请求头线路。中文源优先，全球源补充。分类采用优先来源分类。
- 首次冷启动等待已配置默认频道到达，或全部源返回后回退；有缓存立即使用。后台更新不打断正在播放的频道。
- 播放错误 / 连续缓冲 15 秒时尝试下一条未试线路。每轮有限重试；稳定播放 10 秒后记住成功线路并重置恢复周期。全部失败停止并提供换台 / 重试操作。
- Activity 不可见时释放播放器，返回同一 Activity 时重新播放原频道；重新启动进程则播放指定默认频道。

## 边界

提高最低 Android 版本的价值主要是明确目标和简化维护；性能仍依赖设备解码器与网络。默认使用 Media3 硬件解码器和解码器回退，不附带 FFmpeg 软件解码扩展。支持 HLS / DASH / 普通 HTTP 视频；P2P、原始 UDP 组播、需要 DRM / 登录凭据的源不在首版范围内。HTTP 代理 URL 中出现 `/udp/` 仍是普通 HTTP 流，可尝试播放。

当前源未提供本项目可靠 EPG，所以界面显示频道和真实播放状态，不制造节目名称。不开机自动启动设备应用。

## 验证方法

纯 JVM 单元测试覆盖解析、合并、默认回退和线路恢复；Lint 与 APK 构建检查 Android API 和清单；本地 HTTP 测试源 + 真实 Media3 + ADB 遥控器按键检查默认频道重启、焦点、长按、收藏、故障切换、缓存和空列表。Debug 可通过 Gradle 参数替换测试源，Release 固定真实源。交付 APK 必须正常重建，去除测试参数。

2026-10-02 验证：8 项单元测试通过；Lint 0 errors（12 条建议性警告）；Debug / 未签名 Release 构建通过。在 API 29 Google APIs 系统镜像、TV 1080p 硬件配置模拟器上，使用本地生成的 300 秒 H.264 MP4 和五个 HTTP 列表接口，13 项完整遥控器检查全部通过，AndroidRuntime 未发生崩溃。Android 10 的长按确定事件有显式处理；较新系统通过平台预测返回回调处理返回。

模拟器证明功能与 API 29 兼容性；具体 ARM 盒子的 HEVC / 音频编码、IPv6 连通性与长期直播稳定性仍以真机验证为准。
