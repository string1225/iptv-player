# 看电视 · Android TV IPTV

面向 Android 10 及以上电视 / 盒子的原生 IPTV 客户端。打开应用即播放默认频道，使用遥控器选台。

[下载最新正式安装包](https://github.com/string1225/iptv-player/releases/latest/download/iptv-player.apk)。项目每次更新默认验证、推送代码并发布新版正式 Release，执行规则见 [AGENTS.md](AGENTS.md)。

## 功能

- 首次安装 / 升级到 0.3.3 先用内置 IPv4 线路播放东方卫视；以后主动设置的默认频道也保存独立启动记录，开播不等待完整列表。列表与菜单随后异步加载。
- 按分组浏览，移除“全部频道”；大分组每页最多 100 台，避免上万频道一次提交给界面。
- 来源分组显示 `IPv6 · 分类名`（用户提供的优先源）、`Z · 分类名`（zbds）、`D · 分类名`（补充源）、`I · 分类名`（iptv-org），顺序为 IPv6、Z、D、I。同名频道保留各来源分组入口，共用默认设置和备用线路。
- 地方频道使用两级菜单：地方频道 → 省级地区 → 频道，只有进入地方分类时才显示地区列。按城市 / 区县名称及来源元数据归类，无法可靠识别的台保留在“其他地区”。
- “我的收藏”固定为分组第一项；支持全局频道名称查询（中文、大小写、空格 / 连字符规范化）、默认频道标记和数字编号选台。
- 同一频道的重复条目合并为播放线路；支持手动切换、错误 / 缓冲超时自动换线路。
- 按 URL + 请求头缓存各线路的实际播放可用性。上下换台跳过全部线路失败或手动标为不可用的频道；菜单仍可选择重试，手动停用可取消。
- M3U / TXT 解析，支持 `#genre#` 分类、IPv6 地址、User-Agent / Referer 请求头。
- 用户 `IPV6.m3u` 保留 77 条实测有效 IPv6 线路，Z 两份列表分别保留 410 / 518 条记录，均随 APK 内置；同名频道选台优先尝试用户源，已失败线路让位于备用。另有 8 个远端源以最多 5 个任务并行更新，各自缓存；GitHub 列表优先加速站，失败回退原地址。
- 启动只读取小型默认频道记录，随后后台读取内置列表、缓存并静默更新远端源；索引、解析和搜索均在后台执行，列表变化不打断当前播放。源下载失败不覆盖默认频道设置。
- GitHub Release 手动 / 自动更新：默认开启后台检查和下载，加速站优先、GitHub 回退；校验通过后在菜单中安装。
- Media3 / ExoPlayer 播放 HLS、DASH 和普通 HTTP 视频。MP2（MPEG-1 Layer II，32 / 44.1 / 48 kHz、单 / 双声道）随包软件解码为 16 位 PCM，其他格式继续使用系统解码器并允许解码器回退。
- 线路缺少可播放的音轨时自动切换备用线路；只有音轨已选中的稳定播放才记为可用，避免“有画面无声音”被误记为成功。

“自动播放”指打开应用后的行为。缓存只保存频道列表，观看仍需联网。IPv6 线路需设备网络支持 IPv6。

## 遥控器

| 按键 | 全屏播放 | 频道列表 |
| --- | --- | --- |
| 确定 | 打开列表 | 播放选中频道 |
| 上 / 下 | 当前分组上一台 / 下一台，跳过不可用台 | 分类列连续切分类，频道列移动焦点 |
| 左 / 右 | 上一条 / 下一条线路 | 分类 → 地区 → 频道；左键退回上一列 |
| 菜单 | 当前频道设置 | 选中频道设置 |
| 长按确定 | 打开列表 | 默认频道、收藏、线路等操作 |
| 数字键 | 输入频道编号后跳转 | 搜索框输入 |
| 频道 + / - | 当前分组上一台 / 下一台 | 上一页 / 下一页 |
| 搜索键 / 搜索按钮 | — | 输入名称查询所有分组 |
| 播放 / 暂停 | 暂停或继续 | — |
| 返回 | 连按两次退出 | 地方菜单逐级返回；普通分类关闭列表 |

设置默认频道：确定打开列表 → 选中频道 → 菜单 / 长按确定 → **设为默认频道**。之后重新打开应用会自动播放该频道，列表中显示 `★`。默认频道和收藏为独立设置。

仅有方向键的遥控器：列表首个频道 / 首个分类按 **上** → 聚焦 **搜索** → 确定输入名称。搜索框向下返回分类或查询结果。分类获得焦点就显示对应频道，可连续上下切换，按右或确定进入频道列。

地方分类按右 / 确定先进入地区，地区可以连续上下切换，再按右 / 确定进入频道；左 / 返回逐级退回。重新打开列表会恢复当前播放频道的地区及所在页，全屏换台限于该地区。大地区、收藏和名称查询仍每页最多 100 台。

不可用状态来自播放错误 / 连接超时；未测试线路仍会尝试，只有全部线路失败才自动跳过。选台时先尝试未失败的内置 IPv6 线路，其他线路按“已可用 → 未测试 → 已失败”排序；连续播放 10 秒记为可用，自动失败标记随之恢复。原 URL / 请求头改变后视为新线路。手动停用独立保存，即使重试成功也需菜单取消，不改变已设置的默认频道。数字键输入不可用台编号会打开列表，不直接播放，需在菜单选择重试。

## 内置频道源

首选为 [用户提供的 IPV6.m3u](app/src/main/assets/playlists/IPV6.m3u)。0.3.3 逐条验证用户源和 Z·直播电视（zbds）：1,158 条原记录对应 703 条不同 URL＋请求头线路，590 条通过实际媒体与音频解码，113 条多轮未通过；删除对应 146 条记录，并去掉 7 条重复记录。结果反映检测时的网络，不代表线路在所有地区永久失效。

内置快照保留用户源 77 条、[Z IPv4 M3U](app/src/main/assets/playlists/zbds4m3u.m3u) 410 条、[Z IPv4 TXT](app/src/main/assets/playlists/zbds4txt.m3u) 518 条。实测仅有音频的 34 条不同线路标为“广播”，放入广播分类，避免成为同名电视台的备用线路。Z 两个 IPv6 列表当前只有更新公告，已移除。三份快照随应用版本更新，刷新不会重新导入未经复核的 Z 上游坏线路；D 补充源与 I 全球源仍后台更新，本轮未逐台审查。检测方法、摘要与逐线路结果见 [源检查说明](docs/iptv-sources.md) 和 [审查记录](docs/channel-audit-20261031.json)。

东方卫视即时启动使用两条已验证的百视通 IPv4 线路；完整列表到达后保留当前连接，手动选台与后续故障恢复继续使用合并后的优先源和备用线路。用户 IPv6 快照观看仍需设备具备有效的 IPv6 网络。

播放线路先合并内置 IPv6 源，再依次合并 zbds、补充源和全球源；全球列表规模较大，后台更新不会阻塞内置列表及已有缓存播放。下载成功不等于每条直播线路都能播放，可在菜单中查看源状态 / 选择线路。

0.3.0 从 [dongyubin/IPTV](https://github.com/dongyubin/IPTV) 收集了 30 个公开列表地址，接入已复核可解析的 7 个补充源：myernestlu、zbefine、茶客、BigBigGrandG、Kimentanm、YanG、范明明；加入在 zbds 与 iptv-org 之间。镜像、已由全球源覆盖的子列表和本次无法读取的地址避免重复接入。详见 [源整理与检查结果](docs/iptv-sources.md) 和 [JSON 清单](docs/iptv-sources.json)。

## 构建

- Android Studio，JDK 25（本项目验证版本）、Android SDK 36 / Build Tools 36.0.0。
- Gradle Wrapper 9.5.0，Android Gradle Plugin 9.3.0（内置 Kotlin），Media3 1.11.1。
- `minSdk = 29`，`compileSdk = targetSdk = 36`。最低版本不决定硬解能力，实际播放能力取决于设备芯片和系统解码器。

用 Android Studio 打开仓库。命令行设置 `JAVA_HOME`、`ANDROID_HOME`，或者在未跟踪的 `local.properties` 中设置 SDK 路径：

```powershell
./gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

macOS / Linux 使用 `./gradlew`。可安装的调试 APK：`app/build/outputs/apk/debug/app-debug.apk`。发布版需要自行配置签名；仓库不保存私钥或签名证书。

```powershell
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

GitHub Actions 对提交执行单元测试、Lint 和 APK 构建，成功后提供 APK 工件。

## 软件更新与发布

菜单 → **软件更新**：检查更新 → 下载新版 → 安装新版。自动更新默认开启；应用处于前台时每 6 小时检查一次，第一次打开会延迟 10 秒检查。自动下载不弹安装界面、不打断直播；准备好后提示到菜单安装，可在更新界面关闭自动更新。关闭后仍可手动检查和下载。

正式更新查询 `string1225/iptv-player` 的 GitHub `releases/latest`，只接受正式版本 `v主版本.次版本.修订号` 中的 `iptv-player.apk`。下载首先使用 `https://gh-proxy.org/https://github.com/.../releases/download/.../iptv-player.apk`，HTTP 失败、截断、校验失败均回退原下载地址。校验 GitHub 返回的 SHA-256、实际大小、APK 包名、版本、最低系统版本和签名；不同签名不能覆盖更新。

Android 10 安装需要用户允许“安装未知应用”，然后在系统安装界面确认。APK 保存在应用私有目录，通过 FileProvider 授权安装器读取，重启后仍可继续安装。详细签名和发布步骤见 [Release 发布配置](docs/releasing.md)。每次更新推送代码后还要推送新版标签，等待 Release 工作流发布成功；仅推送源码不会触发客户端更新。v0.3.1 沿用已交付安装包的签名，支持从 0.3.0 覆盖升级。

## 结构与参考

`catalog` 负责解析、频道身份 / 合并和索引 / 分页；`data` 负责列表下载、原子缓存和偏好；`playback` 负责播放及线路恢复；`update` 负责 Release 查询、校验和下载；`ui` 负责电视焦点和界面；`MainActivity` 连接生命周期与遥控器交互。

- [参考 APK 分析与源调查](docs/apk-research.md)
- [首版设计与取舍](docs/android-tv-design.md)

首版不含节目单 EPG、回看、P2P 私有协议、设备开机自启动或账号系统。不申请电话状态和共享存储权限；使用网络权限、更新安装请求权限，以及 Media3 合并的普通 WAKE_LOCK 权限。

## 音频解码器许可

MP2 解码使用未经修改的 [JLayer 1.0.1](https://repo.maven.apache.org/maven2/javazoom/jlayer/1.0.1/)，遵循 LGPL-2.0-or-later。完整许可和来源见 [NOTICE](app/src/main/assets/licenses/NOTICE.txt)，应用菜单也提供“开源许可”。每个正式 Release 附带 `decoder-sources.zip`，包含完整 JLayer 源码 JAR 和许可；应用源码和重建所需配置随版本标签提供。应用其余代码仍遵循仓库的 MIT 许可。
